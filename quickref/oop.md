# Object Oriented Programming

## Takeaways

- Most languages have encapsulation and abstraction capabilities, but inheritance is unique to OOP languages like python, java, etc. Go is apparently not one of those languages so will be interested to see how that works

## Polymorphism

- `Polymorphism` is another trait most common in OOP languages. This is the ability of a function, class, variable, or object to take on multiple forms. For example if multiple classes have a `move()` method, but each has its own implementation, you can still call them all the same
- `Duck typing` is another term here. "If it looks like a duck, quacks like a duck...". Basically defined by what it can do rather than being explicitly declared
- Operator override is a form of polymorphism
